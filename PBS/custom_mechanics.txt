# 1. CICLO DÍA/NOCHE DINÁMICO Y REGLAS DE SUPERVIVENCIA NOCTURNA
#===============================================================================
# Concepto:
#   El paso del tiempo en Oniria Noir es dinámico. Las noches son letales y
#   representan un reto de supervivencia para el jugador.
#
# Reglas y Efectos:
#   - Reloj: REM_NIGHT_START_HOUR = 20 (20:00), REM_DAY_START_HOUR = 8 (08:00).
#   - Nivel salvaje nocturno: Multiplicador REM_NIGHT_LEVEL_MULT (los Pokémon
#     salvajes nocturnos aparecen a niveles mucho más altos y peligrosos).
#   - Salto de Level Cap: Los salvajes nocturnos ignoran el Level Cap del jugador.
#   - Prohibición de captura: De noche está prohibido capturar Pokémon salvajes.
#   - Tinte visual: Tintado adaptativo onírico frío sobre mapas y personajes.
#
# Funciones públicas de script:
#   pbRemIsNight?              -> Retorna true si actualmente es de noche.
#   pbSetNight(night, freeze)  -> Pasa la hora a día o noche y permite congelar reloj.
#   pbToggleDayNight(freeze)   -> Alterna entre día y noche al instante.
#   pbRemTimeFree              -> Descongela el reloj dinámico.
#
# Archivos:
#   tools/scripts_dump/rem_mechanics.rb
#   tools/scripts_dump/src/184_Fake_Time.rb

# 2. SACO DE DORMIR NOIR (:SLEEPINGBAG, ID 719)
#===============================================================================
# Concepto:
#   Herramienta clave para gestionar la supervivencia nocturna en rutas.
#   Permite acampar y pasar la noche hasta el amanecer (08:00 AM) con cargas
#   limitadas para obligar a una gestión táctica de los descansos.
#
# Reglas y Efectos:
#   - Cargas: Empieza con 1 carga. Mejorable hasta 3 cargas máximas.
#   - Recarga: Se recarga automáticamente al 100% al curar al equipo en cualquier
#     Centro Pokémon o al dormir en las camas del segundo piso.
#   - Restricción de uso: Solo se puede usar de noche ("Solo se puede usar de noche.").
#   - Si está vacío: "El Saco de Dormir está vacío. Se recarga en un Centro Pokémon."
#   - Confirmación: "¿Quieres dormir hasta el amanecer?"
#   - Al usar con éxito: Sonido de recuperación, gasta 1 carga, avanza el tiempo a
#     las 08:00 AM (día), refresca la luz solar del mapa y muestra:
#     "¡Ha amanecido! Cargas restantes: X/Y."
#   - Integración en Menú de Pausa: Cajita Oniria Noir justo debajo del Pokévial.
#     Muestra cargas en ámbar o gris, icono pixel art propio (item719.png) y atajo
#     rápido con la tecla física [D] ("D: usar").
#
# Funciones públicas de script:
#   pbRemSleepBagMax           -> Cargas máximas actuales (1..3).
#   pbRemSleepBagCharges       -> Cargas disponibles.
#   pbRemSleepBagUpgrade       -> Sube +1 carga máxima (hasta 3) y rellena.
#   pbRemSleepBagRefill        -> Rellena las cargas al máximo actual.
#
# Archivos:
#   PBS/items.txt (ID 719, SLEEPINGBAG)
#   Graphics/Icons/item719.png (Icono pixel art 48x48)

# 4. HERRAMIENTAS CLAVE DE CAMPO (REEMPLAZO TOTAL DE MOs)
#===============================================================================
# Concepto:
#   Se elimina por completo la necesidad de aprender Máquinas Ocultas (MOs) en
#   los movimientos de los Pokémon y se eliminan los requisitos de medallas.
#   Los obstáculos de campo se resuelven mediante 4 Objetos Clave de la mochila.
#
# Objetos y Mecánicas:
#   1. TIJERAS (:SHEARS, ID 688) -> Reemplaza a Corte (Cut)
#      - Obstáculo: Arbustos, maleza y árboles pequeños (eventos "Tree").
#      - Con objeto: "Hay maleza y ramas que bloquean el camino.\1 ¿Quieres cortarlas con las Tijeras?"
#      - Sin objeto: "Hay maleza y ramas bloqueando el paso. Con unas tijeras de podar se podría cortar fácilmente."
#
#   2. PICO (:PICKAXE, ID 689) -> Reemplaza a Golpe Roca (Rock Smash)
#      - Obstáculo: Rocas quebradizas agrietadas (eventos "Rock").
#      - Con objeto: "Esta roca parece quebradiza y agrietada.\1 ¿Quieres picarla con el Pico?"
#        (Incluye posibilidad de encuentro salvaje de roca).
#      - Sin objeto: "Es una roca agrietada y quebradiza. Con un pico de minero se podría romper fácilmente."
#
#   3. GUANTES DE FUERZA (:GLOVES, ID 690) -> Reemplaza a Fuerza (Strength)
#      - Obstáculo: Rocas pesadas (eventos "Boulder").
#      - Con objeto: "Es una roca enorme y pesada.\1 ¿Quieres usar los Guantes de Fuerza para empujarla?"
#        Activa $PokemonMap.strengthUsed = true y permite empujar rocas en el mapa.
#        Si ya se equiparon: "Los Guantes de Fuerza te permiten mover rocas pesadas."
#      - Sin objeto: "Es una roca enorme. Demasiado pesada para moverla con las manos desnudas."
#
#   4. TABLA DE SURF (:SURFBOARD, ID 691) -> Reemplaza a Surf
#      - Obstáculo: Agua navegable profunda (PBTerrain.isSurfable?).
#      - Con objeto: "¿Quieres navegar con la Tabla de Surf?" (Activa pbStartSurfing() y música de surf).
#      - Sin objeto: "El agua es profunda y cristalina. Necesitarías una tabla de surf para navegar sobre ella."
#
# Formas de activación:
#   - Interacción directa con el botón [C] / [Espacio] frente al obstáculo o agua.
#   - Usar el objeto directamente desde el bolsillo de Objetos Clave de la Mochila.
#
# Archivos:
#   PBS/items.txt (IDs 688, 689, 690, 691)
#   tools/scripts_dump/src/102_PField_HiddenMoves.rb
#   tools/scripts_dump/src/116_PItem_ItemEffects.rb

# 14. INTELIGENCIA ARTIFICIAL COMPETITIVA Y TÁCTICA (REM_AI)
#===============================================================================
# Concepto:
#   Evolución integral del motor de IA de combate de Pokémon Essentials inspirada
#   en los estándares competitivos de Pokémon Añil, Realidea Spark y Berilo.
#   Combate serio, desafiante y táctico sin trampas (Cero Input Reading).
#
# Pilares Clave Implementados:
#   1. Visión y Cálculo de 2HKO:
#      - Reconoce cuándo un movimiento asegura el KO en 2 turnos (>= 50% de daño).
#      - Si la IA tiene la iniciativa (mayor velocidad o prioridad), prioriza
#        cerrar el combate en vez de distraerse con estados innecesarios.
#   2. Prohibición de Setup Suicida (Anti-Suicide Setup):
#      - Si la IA está en rango de ser noqueada en el turno o su salud es crítica
#        frente a un rival más veloz, queda vetado usar movimientos de subida de
#        estadísticas (Danza Espada, Paz Mental, etc.). Forzado a golpear o usar prioridad.
#   3. Castigo al Boost del Jugador (Anti-Sweeper):
#      - Si el jugador acumula >= +2 en Ataque, Atk Especial o Velocidad:
#        * Prioridad masiva a movimientos de reseteo/phasing (Niebla, Remolino, Rugido, Mofa).
#        * Prioridad a estados incapacitantes (Fuego Fatuo a físicos, Onda Trueno a veloces).
#        * Prioridad a movimientos con prioridad (+1) para arañar daño antes de caer.
#   4. Reemplazo Quirúrgico tras KO (pbChooseBestNewEnemy):
#      - Al debilitarse un Pokémon, la IA evalúa en el banquillo:
#        a) Supervivencia defensiva (resistencias e inmunidades al tipo del jugador).
#        b) Amenaza ofensiva (STAB y supereficacia contra el Pokémon activo).
#        c) Velocidad e iniciativa (atacar primero).
#        d) Daño residual de Trampa Rocas (evita sacar Pokémon que mueran al entrar).
#   5. Instinto Depredador en Pokémon Salvajes:
#      - En lugar de elegir movimientos al azar (100 planos), evalúan daño real y STAB.
#      - Rematan al jugador si tienen el KO a tiro y no repiten estados inútiles.
#   6. Control de Peligros de Entrada (Hazards) en Cambios Voluntarios:
#      - Verifica si el campo tiene Trampa Rocas / Púas; descarta cambios a Pokémon
#        que se debilitarían al pisar las rocas.
#   7. Destrezas (Skills) Competitivas por Tipo de Entrenador:
#      - Jefes / Líderes / Alto Mando / Morfeo Élite: Skill 100 garantizado.
#      - Entrenadores Guay / Veteranos: Skill 70.
#      - Especialistas (Karatekas, Psíquicos, Médicos, Rangers): Skill 48.
#      - Suelo mínimo absoluto para cualquier entrenador del juego: Skill 32.
#
# Archivos:
#   tools/scripts_dump/rem_ai.rb (Módulo central REM_AI)
#   PBS/trainertypes.txt (Skills asignados por clase)
#   Data/trainertypes.dat (Compilado binario)
#   tools/scripts_dump/compile_scripts.py (Inyección en Scripts.rxdata, secc. 205)
